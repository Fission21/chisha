# 吃啥 🍽️

> 解决健身人士「今天吃什么、怎么做才好吃」的网站。

**一句话定位**：输入身体信息和目标（增肌 / 减脂 / 维持），自动算出每日热量与三大营养素目标，推荐匹配的食谱，并给出专业、可执行、好吃的菜谱（热量 / 营养素、食材克数、步骤、烹饪技巧）。

## 核心功能

1. **身体档案**：身高 / 体重 / 年龄 / 性别 / 体脂率 / 活动量 / 目标 / 偏好忌口
2. **营养计算**：BMR → TDEE → 每日热量 + 蛋白质 / 碳水 / 脂肪目标
3. **吃什么**：按营养目标匹配推荐食物与菜谱（早 / 午 / 晚 / 加餐）
4. **怎么做**：专业菜谱（食材克数、步骤、热量营养素、烹饪技巧、替代方案）
5. **进阶**：一周餐单、购物清单、饮食记录、AI 菜谱生成（后续）
