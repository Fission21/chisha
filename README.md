# 吃啥 🍽️

> 解决健身人士「今天吃什么、怎么做才好吃」的网站。

**一句话定位**：输入身体信息和目标（增肌 / 减脂 / 维持），自动算出每日热量与三大营养素目标，推荐匹配的食谱（中餐 + 全球做法），并给出专业、可执行、好吃的菜谱（食材克数、步骤、火候、营养、技巧）。

## 快速开始（Docker）

```bash
docker compose up -d --build
# 前端  http://localhost:3200
# API    http://localhost:8000/docs
```

首次启动会自动导入数据（1741 条食材营养 + 77 道菜谱）。

## 核心功能

1. **身体档案**：身高 / 体重 / 年龄 / 性别 / 体脂率（选填）/ 活动量 / 目标
2. **营养计算**：Mifflin-St Jeor → BMR → TDEE → 每日热量 + 蛋白质 / 碳水 / 脂肪
3. **吃什么**：按营养目标 + 过敏忌口 + 偏好菜系，分早餐 / 午餐 / 晚餐 / 加餐推荐，任选其一即可达标
4. **怎么做**：专业菜谱——食材克数、步骤与火候、每份营养、过敏原、师傅小贴士
5. **一周餐单 + 购物清单**：一键生成 7 天不重样的餐单，并自动汇总采购清单
6. **饮食记录**：按食材/菜谱记录每天吃了什么，实时对照热量与三大营养素目标
7. **收藏**：把喜欢的菜谱收进收藏夹，菜谱库可一键筛选
8. **记住档案**：身体信息自动保存，下次直接继续
9. **账号同步**：注册 / 登录后，档案、收藏、饮食记录云端保存，换设备不丢
5. **数据**：中餐 + 西式 + 日韩东南亚等全球做法，营养由「食材 × 克数」推导

## 技术栈

- 前端：Next.js 15（App Router）+ 自绘 SVG 图标，设计系统见 `DESIGN.md`
- 后端：FastAPI（营养计算 / 规则推荐 / 菜谱 API）
- 数据库：PostgreSQL 16
- 数据管道：`python scripts/build_data.py`（中国食物成分表 + 全球食材补充 → processed JSON）
- 设计规范：已安装 [impeccable](https://github.com/pbakaus/impeccable)（`.codex/skills/impeccable`），视觉世界为「菜市场 · 价签」
