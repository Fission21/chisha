# 调研报告：GitHub 同类项目与数据源

- 调研日期：2026-08-03
- 调研目标：为「吃啥」寻找可复用的开源项目、可用的营养 / 菜谱数据源，以及可借鉴的产品与算法思路。

## 二、营养 / 食物成分数据源（决定「吃什么」的计算基础）

### 首选：中国食物成分表

- **[Sanotsu/china-food-composition-data](https://github.com/Sanotsu/china-food-composition-data)** ⭐ 最相关
  - 内容：《中国食物成分表标准版（第6版）》「能量和食物一般营养成分」，1677 条食物，JSON 格式
  - 字段：可食部、热量（kcal / kJ）、蛋白质、脂肪、碳水、膳食纤维、胆固醇、维生素 A / C / E、钙磷钾钠镁铁锌硒铜锰等 30+ 项
  - 附带：食物 GI（升糖指数）数据
  - 风险：OCR / 视觉模型识别，个别字段准确率不保证；版权归出版社，商用需谨慎
  - 用法：作为核心食材营养库，入库时抽样校对
- 同类补充：npm 包 `@iflow-mcp/ruffood-cn-food-mcp`（约 1725 种食物、25 项营养素 / 100g，同为第 6 版数据）

### 补充：国际 / 通用数据

- **USDA FoodData Central (FDC)**：[官网 API](https://fdc.nal.usda.gov/api-spec/fdc_api.html)，40 万+ 食物，免费 API key，权威，适合补充国际食材
- **Open Food Facts**：[openfoodfacts/openfoodfacts-server](https://github.com/openfoodfacts/openfoodfacts-server)，全球最大开源食品库，开放 API，支持中文产品，可做条形码查询

### 菜品营养估算（进阶）

- **CNFOOD-241**：[yih-f/Chinese-dish-image-classification-and-nutrient-estimation](https://github.com/yih-f/Chinese-dish-image-classification-and-nutrient-estimation)——中国菜品图像识别 + 营养素估算数据集

## 四、营养计算算法参考（行业标准）

- BMR：Mifflin-St Jeor 公式
- TDEE = BMR × 活动系数（1.2 ~ 1.9）
- 增肌 / 减脂热量差额：约 ±300 ~ 500 kcal / 日（按目标与进度调整）
- 蛋白质目标：约 1.6 ~ 2.2 g/kg（按体重或瘦体重）
- 脂肪：约 0.6 ~ 1.0 g/kg，其余热量给碳水

详细公式在《数据方案》中落地为代码。

## 五、结论与选型建议

1. **营养库**：用《中国食物成分表（第6版）》数据（1677 条）作为核心，必要时用 USDA FDC 补充
2. **菜谱库**：先自建 / 精选 200~500 道健身友好菜谱（人工 + AI 辅助，标注热量 / 营养素 / 步骤），后续用 RecipeLLM 的爬虫流程从下厨房 / 美食天下扩充
3. **推荐**：MVP 用规则打分（营养匹配度 + 目标标签 + 偏好过滤），后续加协同过滤 / AI
4. **没有可直接抄的完整竞品**，但每个环节都有可参考的开源实现，路线清晰
