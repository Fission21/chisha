# 技术方案

## 1. 架构

```
[Next.js 前端]  ←→  [FastAPI 后端]  ←→  [PostgreSQL]
                     (营养计算 / 推荐 / 菜谱 API)   (foods / recipes / users)
                     [数据管道：python scripts/build_data.py]
```

Docker Compose 编排三个服务：`db`（Postgres 16）、`api`（FastAPI，启动时自动 seed）、`web`（Next.js 15）。端口：web 3200、api 8000（本机 3000 常被其他服务占用，故避开）。

## 2. 技术栈

- 前端：Next.js 15 + TypeScript + 自绘 SVG 图标 + 纯 CSS 设计系统（见 `DESIGN.md`）
- 后端：FastAPI（SQLAlchemy + psycopg2）
- 数据库：PostgreSQL 16
- 数据管道：Python（pandas / json），`scripts/build_data.py`
- 设计规范：impeccable（`.codex/skills/impeccable`），用 `node .codex/skills/impeccable/scripts/detect.mjs <url|file>` 检测 AI 味

## 3. 推荐算法（规则打分）

```
score(recipe, user) =
  0.45 × 热量匹配 + 0.30 × 蛋白质匹配 + 0.15 × 目标标签匹配
  + 0.05 × 菜系偏好 + 0.05 × 多样性（避免同菜系连续）
```

- 先硬性过滤：过敏原 / 忌口
- 按早 / 午 / 晚 / 加餐各出 Top 3，页面标注「任选其一」

## 4. API（草案已实现）

```
POST /api/plan                  # 身体档案 + 目标 → 每日目标 + 分餐推荐
GET  /api/recipes?meal=&cuisine=&tag=&q=
GET  /api/recipes/{id}          # 菜谱详情（食材 / 步骤 / 营养 / 技巧）
GET  /api/foods?q=              # 食材营养查询
GET  /api/health
```
