# 数据方案

## 1. 数据源选型

| 用途 | 数据源 | 状态 |
|---|---|---|
| 食材营养 | 《中国食物成分表（第6版）》json（Sanotsu 仓库，1677 条） | ✅ 可用 |
| 食材营养补充 | USDA FDC API（国际食材） | ⏸ 需要时接入 |
| 菜谱（中文） | 自建精选库 + 下厨房 / 美食天下爬虫 | 🚧 建设中 |
| 菜谱（训练） | Food.com / Recipe1M | ⏸ V3 推荐算法用 |
| 菜品营养估算 | CNFOOD-241 | ⏸ V3 AI 功能用 |

## 2. 核心数据结构

### foods（食物 / 食材）

```
food_id, name, category, edible(可食部%),
energy_kcal, energy_kj, protein, fat, carbohydrate, dietary_fiber,
cholesterol, vitamin_a, vitamin_c, vitamin_e,
calcium, phosphorus, potassium, sodium, magnesium, iron, zinc, selenium, copper, manganese,
gi(升糖指数), source(数据来源), tags
```

### recipes（菜谱）

```
recipe_id, title, summary, cover_image,
meal_type(早/午/晚/加餐), cuisine, difficulty, cook_time, cost, servings,
ingredients: [{ name, amount_g, food_id? }],   # 关键：每道菜可算出营养
steps: [{ order, text, duration, heat }],        # 关键：专业步骤
tips: [烹饪技巧 / 替代方案],
nutrition: { energy_kcal, protein, fat, carbohydrate, fiber },  # 由食材推导或标注
tags: [健身标签: 高蛋白/低碳水/低脂/增肌/减脂...], allergens
```

## 3. 营养计算逻辑

- **BMR（Mifflin-St Jeor）**
  - 男：10 × 体重(kg) + 6.25 × 身高(cm) − 5 × 年龄 + 5
  - 女：10 × 体重(kg) + 6.25 × 身高(cm) − 5 × 年龄 − 161
- **TDEE** = BMR × 活动系数（1.2 ~ 1.9）
- **目标热量** = TDEE + 调整（增肌 +300~500，减脂 −300~500）
- **蛋白质** = 体重(kg) × (1.6 ~ 2.2，按目标 / 体脂调整)
- **脂肪** = 体重(kg) × (0.6 ~ 1.0)
- **碳水** = (目标热量 − 蛋白质×4 − 脂肪×9) / 4

## 4. 菜谱营养推导

- 每道菜谱的食材带克数 → 与食物成分表 join → 累加得整道菜营养
- 好处：食材库更新时，菜谱营养自动正确；同一种食材在不同菜谱里营养一致
