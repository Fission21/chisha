# 产品设计

## 1. 用户画像

- 核心用户：健身人群（增肌 / 减脂 / 维持），对营养有要求但不想天天自己算
- 场景：不知道吃什么 → 输入身体信息与目标 → 得到推荐 → 照着做

## 2. 核心用户流程

1. 进入 → 填写身体档案（身高、体重、年龄、性别、体脂率（可选）、活动量、目标、饮食偏好 / 忌口）
2. 系统计算：BMI、BMR、TDEE、每日热量、蛋白质 / 碳水 / 脂肪目标
3. 生成今日 / 本周推荐：
   - 每餐推荐（早 / 午 / 晚 / 加餐），每道菜显示热量、蛋白质等营养素
   - 可筛选：偏好、忌口、预算、烹饪时间、厨具
4. 查看菜谱详情：
   - 食材清单（带克数）、步骤（带时间 / 火候）、热量营养素、烹饪技巧、替代方案、成品图
5. 收藏菜谱、加入一周计划、生成购物清单（进阶）

## 3. 页面结构（MVP）

- 首页：输入身体档案 + 目标 → 结果
- 结果页：每日营养目标卡片（热量环 / 三大营养素条）+ 今日推荐餐单
- 菜谱列表页：按标签 / 营养素筛选
- 菜谱详情页：专业菜谱（食材 / 步骤 / 营养 / 技巧）
- 我的：档案、收藏、历史（进阶）

## 4. 功能优先级

### MVP（V1）

- 身体档案 + BMR / TDEE / 宏量营养素计算
- 基于营养目标 + 标签的菜谱推荐（规则打分）
- 菜谱详情（食材、步骤、营养、技巧）
- 77 道精选健身菜谱（人工标注营养，持续扩充）

### V2

- [x] 一周餐单计划 + 购物清单
- [x] 饮食记录（吃了什么，营养素追踪，对照每日目标）
- 收藏 / 评分

### V3

- AI 菜谱生成（拍照识别食材 → 生成菜谱，类似 RecipeLLM）
- 下厨房 / 美食天下菜谱库扩充（爬虫）
- 推荐算法升级（协同过滤 + 内容过滤）

## 5. 用户侧数据模型

- User：身高、体重、年龄、性别、体脂率、活动量、目标、偏好、忌口
- Goal：增肌 / 减脂 / 维持
- DailyTarget：热量、蛋白质、碳水、脂肪（由计算器得出）
